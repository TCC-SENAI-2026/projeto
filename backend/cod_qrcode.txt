exemplo completo usando o Cloudinary para guardar a imagem na nuvem, a biblioteca qrcode para gerar o QR code, e o Flask para gerenciar as rotas da web.
Passo 1: Instalar as dependências
No terminal do seu projeto, instale o Flask, a biblioteca do Cloudinary e a biblioteca do QR Code:
Bash

pip install flask cloudinary qrcode[pil]
Passo 2: O Código Completo (app.py)
Crie um arquivo chamado app.py com o código abaixo. Lembre-se de substituir os dados do Cloudinary pelas suas credenciais reais (você cria uma conta gratuita em cloudinary.com).
Python

import os
import qrcode
import io
from flask import Flask, render_template_string, request, redirect, url_for, send_file
import cloudinary
import cloudinary.uploader

app = Flask(__name__)

# Configuração do Cloudinary (substitua pelos seus dados reais)
cloudinary.config(
    cloud_name = "seu_cloud_name",
    api_key = "sua_api_key",
    api_secret = "seu_api_secret"
)

# ---------------------------------------------------------
# SIMULAÇÃO DE BANCO DE DADOS (Substitua por SQLAlchemy, MySQL, etc.)
# ---------------------------------------------------------
banco_de_dados_simulado = []

# ---------------------------------------------------------
# ROTAS DO FLASK
# ---------------------------------------------------------

@app.route('/')
def index():
    # Página HTML simples com formulário de upload e lista de imagens cadastradas
    html = '''
    <!doctype html>
    <title>Upload de Imagem e QR Code</title>
    <h1>Enviar Nova Imagem</h1>
    <form method=post enctype=multipart/form-data action="/upload">
      <input type=file name=arquivo>
      <input type=submit value=Enviar>
    </form>

    <hr>
    <h2>Imagens e QR Codes Gerados:</h2>
    <ul>
      {% for item in itens %}
        <li>
          <b>ID:</b> {{ item.id }} | 
          <a href="{{ item.url_imagem }}" target="_blank">Ver Imagem na Nuvem</a> | 
          <a href="/qrcode/{{ item.id }}" target="_blank">Ver QR Code</a>
        </li>
      {% endfor %}
    </ul>
    '''
    return render_template_string(html, itens=banco_de_dados_simulado)


@app.route('/upload', methods=['POST'])
def upload():
    if 'arquivo' not in request.files:
        return redirect(url_for('index'))
    
    arquivo = request.files['arquivo']
    
    if arquivo.filename == '':
        return redirect(url_for('index'))

    try:
        # 1. ENVIAR PARA A NUVEM (Cloudinary conversando com o Flask)
        # O upload envia o arquivo direto da memória para os servidores da nuvem
        resultado_nuvem = cloudinary.uploader.upload(arquivo)
        
        # 2. CAPTURAR O LINK PÚBLICO QUE A NUVEM DEVOLVEU
        url_publica = resultado_nuvem['secure_url']
        
        # 3. SALVAR NO BANCO DE DADOS (Simulado aqui por uma lista)
        novo_id = len(banco_de_dados_simulado) + 1
        dados_imagem = {
            "id": novo_id,
            "url_imagem": url_publica
        }
        banco_de_dados_simulado.append(dados_imagem)
        
    except Exception as e:
        return f"Erro ao fazer upload: {str(e)}"

    return redirect(url_for('index'))


@app.route('/qrcode/<int:id_imagem>')
def gerar_qrcode(id_imagem):
    # Procura a imagem no "banco de dados" pelo ID
    imagem_obj = next((item for item in banco_de_dados_simulado if item["id"] == id_imagem), None)
    
    if not imagem_obj:
        return "Imagem não encontrada", 404

    url_alvo = imagem_obj["url_imagem"]

    # Gera o QR Code dinamicamente com o link da nuvem
    qr = qrcode.QRCode(version=1, box_size=10, border=5)
    qr.add_data(url_alvo)
    qr.make(fit=True)
    
    img = qr.make_image(fill_color="black", back_color="white")
    
    # Salva a imagem do QR Code em um buffer de memória (sem precisar criar arquivo físico no PC)
    buffer = io.BytesIO()
    img.save(buffer, format="PNG")
    buffer.seek(0)
    
    # Retorna a imagem do QR Code diretamente para o navegador do usuário
    return send_file(buffer, mimetype='image/png')


if __name__ == '__main__':
    app.run(debug=True)
O que está acontecendo passo a passo nesse código do Flask?
O usuário envia a foto pelo formulário web (request.files['arquivo']).
O Flask pega esse arquivo e repassa ele para o Cloudinary (cloudinary.uploader.upload(arquivo)). Aqui acontece a "conversa": o Flask manda o arquivo, o Cloudinary salva nos servidores dele e devolve um dicionário cheio de informações.
Pegamos a chave secure_url desse dicionário. Essa string é o link oficial e público da imagem na nuvem.
Salvamos esse link no nosso "banco de dados" junto com um ID (num sistema real, você faria algo como db.session.add(Imagem(url=url_publica)) se estivesse usando o Flask-SQLAlchemy).
Quando alguém acessa a rota /qrcode/1, o Flask busca esse link salvo, cria o QR Code na hora usando a biblioteca qrcode e o exibe na tela. Quando a pessoa lê com o celular, abre exatamente a imagem hospedada na nuvem.
Dica para o seu projeto real:
Se no futuro você for usar um banco de dados relacional real no Flask (como PostgreSQL ou MySQL com Flask-SQLAlchemy), a sua tabela de imagens precisará apenas de colunas simples, como:
id (Inteiro, Chave Primária)
url_imagem (Texto/String - onde você guarda o link que a nuvem te deu)
data_criacao (Data/Hora opcional)
